# First non-zero residue: position = smallest prime factor, value = cofactor

`min { k > 0 : C(n,k) != 0 mod n } = spf(n)` and the residue there is exactly `n / spf(n)`.

- composite `n` checked: **2,568**, prime `n` checked: **428** (`n < 3000`)
- failures: **0**
