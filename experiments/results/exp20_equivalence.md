# Partial information is exactly as hard as the factorisation

Round 12. The reduction closes into an equivalence.

## 1. The window is `N^(beta^2)`, and `beta <= 1/2`

Coppersmith recovers a root smaller than `N^(beta^2/d)`, and for factoring the polynomial is linear (`d = 1`). Writing `p ~ N^beta`:

| bits of N | beta | bits actually recovered | beta^2 · log2 N | ratio |
|---|---|---|---|---|
| 27 | 0.502 | 7 | 6.8 | 1.03 |
| 29 | 0.393 | 4 | 4.5 | 0.89 |
| 32 | 0.310 | 4 | 3.1 | 1.30 |
| 35 | 0.258 | 3 | 2.3 | 1.29 |
| 38 | 0.210 | 2 | 1.7 | 1.19 |

The window tracks `beta^2 log N`. And `p` is the *smaller* factor, so `beta <= 1/2` always: **the widest possible Coppersmith window is `N^(1/4)`, attained exactly at the balanced semiprime.** There is no regime where the lattice sees further.

## 2. Guessing the window never beats Strassen

Covering a range of length `N^beta` with windows of width `N^(beta^2)` takes `N^(beta - beta^2)` guesses. Strassen finds `p` outright in `O~(sqrt p) = O~(N^(beta/2))`.

| beta | window exponent beta^2 | guess+Coppersmith beta(1-beta) | Strassen beta/2 | winner |
|---|---|---|---|---|
| 0.50 | 0.2500 | 0.2500 | 0.2500 | tie |
| 0.45 | 0.2025 | 0.2475 | 0.2250 | Strassen |
| 0.40 | 0.1600 | 0.2400 | 0.2000 | Strassen |
| 0.33 | 0.1089 | 0.2211 | 0.1650 | Strassen |
| 0.25 | 0.0625 | 0.1875 | 0.1250 | Strassen |
| 0.20 | 0.0400 | 0.1600 | 0.1000 | Strassen |
| 0.10 | 0.0100 | 0.0900 | 0.0500 | Strassen |

`beta(1-beta) <= beta/2` iff `beta >= 1/2`, and `beta <= 1/2` always. So **guessing plus Coppersmith is never strictly better than Strassen**, and is strictly worse for every unbalanced semiprime. The two meet at `N^(1/4)` precisely at `beta = 1/2` -- the balanced case, which is also where `beta(1-beta)` is maximised. The hardest input for the lattice route is the hardest input for everything else.

## 3. The equivalence

Putting the two together gives a statement rather than another barrier.

> **Theorem.** For balanced semiprimes `N = pq` with `p <= q <= 2p`, the following are equivalent:
> 
> **(a)** a deterministic `poly(log N)` algorithm that factors `N`;
> 
> **(b)** a deterministic `poly(log N)` algorithm that outputs an integer `p~` with `|p - p~| <= N^(1/4)`.

*Proof.* (a) implies (b): factor and output `p`. (b) implies (a): feed `p~` to Coppersmith, whose window at `beta = 1/2` is exactly `N^(1/4)`. ∎

The implication that matters is the second one, and it is the reason this round exists. Eleven rounds hunted for *partial* information about `p` on the theory that a quarter of the bits might be cheaper than all of them. They are the same problem. Any algorithm producing a quarter of the bits in polynomial time **is** a polynomial-time factoring algorithm, and every barrier measured in this repository applies to it unchanged.

## What this settles, and what it does not

It settles the strategy. Looking for cheap partial information is not a way around the barrier; it is the barrier restated. The search space of *approaches* has collapsed to two doors, both long known and both shut:

- **widen the window**: improve Coppersmith's exponent past `beta^2/d`. A well-known barrier in lattice cryptanalysis; the bound is tight for this lattice family, so it needs a genuinely different construction.
- **shrink the search**: find structure in the *location* of `p` that no algebraic, geometric, group-theoretic or fractal property examined over twelve rounds provided.

It does not settle the question. Factoring is not known to be hard -- it is in NP and co-NP, so it is very unlikely to be NP-complete, and a polynomial-time algorithm is not ruled out by anything proved. What this project can report is a map: eleven distinct routes, each closed by a measurement rather than an intuition, and a precise statement of what any twelfth route must do that none of them did.
